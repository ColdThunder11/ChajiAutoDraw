霸王茶姬杯贴自动化绘制工具，在霸王茶姬桌面端微信小程序按照图片进行模拟鼠标绘图，纯Vibe项目，~~能用就行~~  
使用请遵循霸王茶姬本身的杯贴定制规则  


## 使用
前往[Release](https://github.com/ColdThunder11/ChajiAutoDraw/releases)页面下载Windows可执行文件运行  
在微信电脑端打开小程序，进入杯贴创作界面，调整好想要的画笔大小后，收回画笔大小调整面板，如果画布还被其他UI挡住部分请手动调整窗口按大小使得画布完全不被遮挡。点击检测窗口按钮，如果出现画布位置信息则完成设置。打开图片并调整设置到满意后点击开始绘制进行绘制，各个设置项可鼠标悬停在标签上查看详细说明（但是是AI写的看不懂也正常）
